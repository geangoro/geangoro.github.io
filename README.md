# Del TIC al TAC

**Objeto Virtual de Aprendizaje (OVA)**: *Diseña tu actividad de clase con propósito pedagógico.*

Recurso de formación para docentes de sexto y séptimo del Colegio Colsubsidio Maiporé, creado por el Grupo 9 de la Maestría en Innovación Educativa Mediada por TIC (MITE), Universidad El Bosque.

## Estructura

```
index.html      Página única con todo el recorrido (tres momentos + créditos)
css/styles.css  Estilos (accesibilidad, contraste AA, impresión)
js/app.js       Lógica (navegación, progreso, casos, plantilla, descarga)
LICENSE         Licencia CC BY-NC-SA 4.0
```

No requiere servidor, base de datos ni dependencias: funciona abriendo
`index.html` en cualquier navegador, también sin conexión una vez cargado.

## Cómo publicarlo en GitHub Pages (3 pasos)

1. Crea un repositorio **público** llamado, por ejemplo, `ova-del-tic-al-tac`
   en la cuenta `geangoro` y sube todos estos archivos (puedes arrastrarlos
   desde la web de GitHub: *Add file → Upload files*).
2. En el repositorio: **Settings → Pages → Source: Deploy from a branch →
   Branch: main → / (root) → Save**.
3. Espera uno o dos minutos. El OVA quedará disponible en:

   `https://geangoro.github.io/ova-del-tic-al-tac/`

   Ese es el enlace que va en el formulario de entrega.

> Si prefieres el dominio raíz `https://geangoro.github.io/`, crea el
> repositorio con el nombre exacto `geangoro.github.io` y sube los archivos
> ahí (ten en cuenta que ese repo quedaría dedicado a este sitio).
